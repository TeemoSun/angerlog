# 情绪瓶美术风格指南

> 适用范围： angerlog 前端（React + Tailwind CSS v4 + shadcn/ui）
> 文档状态： 已落地，后续视觉调整应与本指南保持一致

## 1. 设计概念

整体定位为 **“疗愈系星空情绪日记”**。用户每一次生气都会被抽象成一颗发光的星星，投入玻璃瓶中。夜晚星空背景代表情绪的广阔与宁静，玻璃瓶与纸张元素则提供安全、可被收藏的仪式感。

核心意象：

- **星空 / 月亮 / 流星** → 情绪的可视化与释放
- **玻璃瓶** → 容纳与承载情绪的安全空间
- **信笺纸张** → 记录、倾诉、治愈

## 2. 色彩系统

所有颜色通过 `frontend/src/main.css` 的 `@theme` 注入为 Tailwind v4 CSS 变量。

| 语义名 | CSS 变量 | 色值 | 用途 |
|--------|----------|------|------|
| **night-900** | `--color-night-900` | `#0b0a1a` | 最深夜空，页面主背景终点、底部渐变 |
| **night-800** | `--color-night-800` | `#15122b` | 夜空主体、卡片深色底 |
| **night-700** | `--color-night-700` | `#1e1842` | 夜空中层、hover 背景 |
| **night-600** | `--color-night-600` | `#2a2258` | 渐变起点、侧光 |
| **star-gold** | `--color-star-gold` | `#f6d365` | 高光星、标题强调、瓶内液体高光 |
| **star-amber** | `--color-star-amber` | `#fbbf24` | 主强调色：按钮、Tab 激活、水位、强度 4-6 |
| **star-orange** | `--color-star-orange` | `#fb923c` | 次强调：液体下层、强度 7-8 |
| **star-red** | `--color-star-red` | `#ef4444` | 高强度预警：强度 9-10、错误提示 |
| **star-crimson** | `--color-star-crimson` | `#dc2626` | 最高强度小球 |
| **paper** | `--color-paper` | `#faf6ed` | 浅色纸张背景（登录卡、dialog 底色） |
| **paper-muted** | `--color-paper-muted` | `#f0e9db` | 纸张阴影/分隔 |
| **ink** | `--color-ink` | `#3d3429` | 纸张上的正文 |
| **ink-light** | `--color-ink-light` | `#7a6f60` | 纸张上的次要文字 |
| **glass** | `--color-glass` | `rgba(255,255,255,0.08)` | 毛玻璃底色 |
| **glass-border** | `--color-glass-border` | `rgba(255,255,255,0.15)` | 毛玻璃边框 |
| **glass-strong** | `--color-glass-strong` | `rgba(255,255,255,0.12)` | 悬浮/激活态毛玻璃 |

使用约定：

- 背景统一使用深紫夜空渐变，**禁止**使用纯白/灰白背景做主容器。
- 卡片、头部、Tab 等容器优先使用 `glass` / `glass-border` 或 `bg-white/5` + `backdrop-blur`。
- 强调色只用 `star-amber` / `star-gold` / `star-orange`，红色仅用于高强度与错误。

## 3. 字体

| 用途 | 字体 | 类名 |
|------|------|------|
| 标题 / 手写感标题 | LXGW WenKai | `font-hand` |
| 正文 / UI | Noto Sans SC Variable | 默认 sans |

配置在 `frontend/src/main.css`：

```css
--font-sans: "Noto Sans SC Variable", ui-sans-serif, system-ui, sans-serif;
--font-hand: "LXGW WenKai", "PingFang SC", "Microsoft YaHei", cursive;
```

标题类场景（如 logo “情绪瓶”）使用 `font-hand`，正文保持默认无衬线以保证可读性。

## 4. 页面氛围

- 全屏深紫渐变背景：`bg-gradient-to-b from-[#2a2258] via-[#15122b] to-[#0b0a1a]`。
- 固定全屏粒子层（`ParticleBackground`）：缓慢闪烁的星星 + 偶尔划过的流星。
- 装饰月亮：右上角 `bg-amber-100/8 blur-3xl` 的大圆光晕，叠加 `from-amber-100/12 to-amber-300/5` 的小圆渐变。
- 底部暗角：`bg-gradient-to-t from-night-900/80 to-transparent`，防止内容贴底割裂。
- 所有层通过 `z-0` / `z-10` / `z-30` / `z-40` 分层：背景 < 月亮 < 粒子 < 页面内容 < 底部 Tab。

## 5. 玻璃拟态组件

通用玻璃卡片样式（以 `Card` 组件为基准）：

```css
rounded-2xl border border-white/10 bg-white/5 text-slate-100 shadow-xl shadow-black/20 backdrop-blur-xl
```

强调/选中态玻璃：

```css
bg-gradient-to-r from-star-gold/20 to-star-amber/20 ring-1 ring-star-amber/40
shadow-[0_0_12px_rgba(251,191,36,0.15)]
```

悬浮按钮：

```css
bg-gradient-to-r from-amber-500 to-orange-500 text-white shadow-lg shadow-amber-900/30
hover:from-amber-400 hover:to-orange-400
```

## 6. 瓶子视觉

- 玻璃瓶身使用 SVG 绘制，带透明玻璃高光（`glassGrad`）与瓶底阴影。
- 瓶内液体/水位：暖金到橙的线性渐变，半透明星光感。
- 瓶内小球为五角星形，按强度分层着色：
  - 1-3：淡黄/金
  - 4-6：琥珀
  - 7-8：橙
  - 9-10：红/深红
- 瓶口悬浮标签提示“✨ 扔一颗星星”，使用 `bg-amber-400/20` + 细环。
- 水位从底部 15% 起算，随记录数线性上升至约 95%。

## 7. 表单与 Dialog

- 弹窗/表单卡片使用 `paper` 色背景 + `ink` 文字，营造“写在信笺上”的感觉。
- 输入框使用深色玻璃：`bg-night-900/40 border-white/10` 或纸张变体 `bg-paper/5`。
- 提交按钮使用强调渐变。
- 高强度（≥8）提交前显示 4-7-8 呼吸引导：圆形缩放 + 柔和发光。

## 8. 响应式

- 桌面端：顶部 header 含 logo / TabBar / 退出按钮；三列 summary 卡片。
- 移动端：底部固定 Tab 导航；瓶子自适应高度；summary 单列；Dialog 全屏或 nearly full-screen。

## 9. 图标与 emoji

- 不使用额外图标库，统一用 emoji 保持手绘/轻量感：
  - 瓶子：🫙
  - 记录：✉️
  - 统计：📈
  - 星星：✨
