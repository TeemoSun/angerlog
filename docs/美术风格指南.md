# 情绪瓶美术风格指南

> 适用范围：angerlog 前端（React + Tailwind CSS v4）
> 文档状态：设计定位为「治愈系暗夜星空风」，后续视觉调整均应与本指南保持一致

## 1. 设计概念

整体定位为**治愈系暗夜星空风 H5**。核心用「暗调夜空 + 暖调卡片」的柔和对比，把「生气」的负面情绪转化为「收纳星星」的浪漫意象。整体气质温柔软糯、无攻击性，全程弱化尖锐感，主打情绪安抚的视觉感受。

核心意象：

- **星空 / 月亮 / 流星** → 情绪的广阔与宁静
- **玻璃瓶** → 收纳与承载情绪的安全空间（轻拟物、木塞、通透）
- **米杏色纸卡片** → 记录、倾诉、治愈的信笺感

## 2. 整体色彩系统

色彩逻辑：

- **基底色**：低饱和深紫黑系（冷调基底，静谧夜空）
- **内容色**：暖调米杏 / 奶白系（暖调承载内容，柔和不刺眼）
- **强调色**：黄 → 橙 → 红 → 深红的星星渐变色系（对应生气等级）
- **中性色**：全链路避免纯黑、纯白，全部使用带色调的低饱和中性色（深棕、米白、浅灰棕）

使用约定：

- 背景统一使用低饱和深紫渐变，**禁止**纯白/灰白背景。
- 内容承载优先用暖调米杏卡片；深色背景上的辅助容器（Tab、筛选、玻璃按钮）使用半透明磨砂玻璃。
- 强调色只用星星渐变（黄/橙/红/深红），红色仅用于高等级与错误。
- 全链路避免纯黑纯白：深底上的文字用暖米白，浅底上的文字用深棕褐 / 浅棕灰。

## 3. 字体系统

全项目采用「手写标题体 + 圆润无衬线正文」的组合，层级清晰、气质统一。

**标题字体（大文案用）**

- 风格：治愈系手写体，笔画有自然的粗细变化，带轻微连笔感，笔触随性但辨识度高，类似温柔的手写钢笔字。
- 颜色：深底上用暖米白（非纯白，带极淡黄调），浅底上用深棕褐（非纯黑）。
- 排版：全部居中，行距宽松、字距适中、上下留白充足。

**正文字体（功能/说明用）**

- 风格：圆润无衬线体，笔画端点与转角全部圆角处理，常规字重，气质温和软糯。
- 颜色规则：
  - 深色背景上的按钮文字：暖米白
  - 浅色卡片上的主文字：深棕褐
  - 浅色卡片上的辅助文字（日期、说明）：浅棕灰，比主文字浅一度
  - 输入框占位符：浅灰棕，透明度偏低

**字号层级**（从大到小）：

1. 页面大标题（手写体）
2. 按钮文字 / 卡片标题
3. 正文内容 / 选项文字
4. 日期 / 辅助说明文字
5. 占位符 / 最弱提示文字

## 4. 背景系统

1. **主背景**：低饱和深茄紫色渐变，非纯色。画面中心/上方稍亮、偏灰的深紫；边缘/下方渐变为更深的紫黑，过渡极柔和、无明显边界，哑光无光泽，不抢主体。
2. **星空装饰**：背景全域随机分布细碎白色圆点，正圆形、边缘柔化无硬边；大小不一、疏密有致，绝大多数是极细小点，低不透明度、稀疏留白，仅营造氛围。
3. **月亮装饰**：固定在右上角，暖土黄色满月；径向渐变填充（中心亮、边缘稍暗），边缘柔化模糊、无清晰轮廓线，尺寸小巧，仅作背景点缀。
4. **首页暗纹**：首页背景中心有一个半透明的瓶子剪影，透明度极低，仅作视觉锚点暗纹，与页面上的实体瓶子造型完全一致。

图层关系（自下而上）：主背景 → 月亮 → 星空粒子 → 页面内容 → 底部导航。

## 5. 核心视觉：瓶子插画

瓶子是核心视觉符号，采用**轻拟物扁平化**风格，主打玻璃通透感。

- **造型**：圆润无尖角；瓶身为大圆角矩形，瓶颈短而圆润，瓶口配圆形木塞，整体敦实可爱；瓶身居中，底部带淡淡的椭圆形柔和阴影，模拟轻微悬浮感。
- **瓶身**：极细的浅白色轮廓线勾勒，线条柔和不锐利；填充为半透明灰紫，比背景底色稍亮，能隐约透出背景的星空。
- **高光**：瓶身左右两侧极细的竖向高光线条，微弱表现玻璃反光，点到即止。
- **木塞**：浅棕黄色（卡其色），带上下渐变表现木质体积感，边缘圆角。
- **瓶内星星**：圆角五角星造型（无尖角），带轻微径向渐变（中心亮、边缘深）与微弱发光；颜色对应生气等级（黄 → 橙 → 红 → 深红），沉在瓶底，数量对应记录条数。
- **液体**：暖金到橙的线性渐变、半透明星光感；从瓶底约 15% 起算，随记录数线性上升至约 95%，水面带柔和高光。

## 6. 按钮组件

全项目按钮统一遵循「大圆角、低对比、柔质感」，分四类：

1. **首页主按钮**（深色背景上半透明）：超大圆角矩形（接近胶囊），半透明磨砂玻璃质感（低不透明度灰底 + 同系色细亮边描边）；图标左、文字右水平居中；图标线性手绘、浅金色，文字暖米白。
2. **卡片主按钮**（浅色卡片上实色）：超大圆角矩形，浅卡其（奶驼色）实色填充、低饱和暖调；白色圆润文字居中，可配小型星星图标（如「折成星星」提交按钮）。
3. **二级操作按钮**：保存按钮填充对应生气等级的主题色（黄/橙/红/深红）、白色文字，视觉权重高；取消按钮浅灰底、深灰字，权重低，形成主次对比。
4. **生气程度选项按钮**：正方形大圆角卡片、白色底色，上方为对应颜色圆角星星图标、下方为文字，居中排列，扁平柔和，默认无描边。

## 7. 卡片与弹窗

内容承载容器统一为暖调米杏「便签纸」质感，分两类：

**弹窗大卡片（写信弹窗、信件列表弹窗）**

- 超大圆角矩形，四角圆弧半径极大，像一张圆润的便签纸，无任何直角。
- 暖调米杏色（奶白带极淡黄调）底色；底部柔和深色投影，模糊度高、透明度低，仅表现悬浮感。
- 顶部为日期区，文字浅棕灰、字号偏小；日期区下方一条极细浅棕色分割线；内容区留白充足，输入框为沉浸式无边框设计（底色与卡片一致，仅靠占位符指示）；关闭按钮为右上角圆形浅灰底、深灰叉号，尺寸小巧。

**列表项小卡片（单条信件）**

- 同样大圆角、米杏色底。
- 卡片最左侧一条竖向色条，颜色对应记录的情绪等级，作为快速识别标识。
- 右上角为胶囊形等级标签，填充对应主题色、白色小字。
- 内容结构自上而下：日期时间 → 正文内容 → 消气原因输入区；输入区为浅灰细边框、圆角，浅灰占位符文字。

## 8. 表单交互

- 写信弹窗整体为信笺卡片：日期 + 极细分割线 + 沉浸式无边框内容输入。
- 生气程度选择使用白色圆角卡片（上方等级星星、下方文字），选中态给出柔和强调。
- 高强度（≥8）提交前展示 4-7-8 呼吸引导（圆形缩放 + 柔和发光），再进入提交。
- 提交按钮为「折成星星」类卡片主按钮风格，保存按钮按等级主题色处理。

## 9. 图标与装饰

- **星星图标**：全项目统一使用圆角五角星（无尖角），按等级用黄 → 橙 → 红 → 深红渐变，中心亮、边缘深，微弱质感。
- **功能小图标**：铅笔、菱形分隔符等，统一线性风格、圆角处理，颜色与对应文字一致。
- **通用规则**：所有装饰元素全部柔边、圆角，杜绝任何尖锐直角、尖角，全程贯彻「柔软治愈」的视觉感受。

## 10. 响应式

- 桌面端：顶部 header 含 logo / Tab 导航 / 退出按钮；三列摘要卡片。
- 移动端：底部固定 Tab 导航；瓶子自适应高度；摘要卡片单列；弹窗接近全屏。

## 11. 通用设计法则

1. **全圆角原则**：所有可见元素（按钮、卡片、图标、输入框、标签）全部使用大圆角，零直角、零尖角，是这套风格最核心的识别点。
2. **低对比原则**：全程避免高饱和、强对比，文字与背景对比度柔和，所有颜色降低饱和，主打舒适感。
3. **大留白原则**：所有区域留白充足，元素间距宽松、排版疏朗，营造松弛的情绪氛围。
4. **冷暖平衡原则**：冷调深紫背景 + 暖调米杏卡片 + 暖调星星强调色，冷而不阴、暖而不燥。
5. **弱质感原则**：所有拟物效果（玻璃、木塞、阴影）点到为止，以扁平化为基底、轻微加质感，保持轻盈感。
